Сиёсати махфият

Охирин навсозӣ: 25 ноябри 2026

Хулоса: барои ҳамаи корбарон регистрация ҳатмист. Ном, насаб (ихтиёрӣ), синну сол ва логин дар Supabase нигоҳ дошта мешаванд. Ёддоштҳо, нақшаҳо, ҳисоботҳо, рӯйдодҳо ва сабтҳои даромаду хароҷот низ ба ҳисоби худи корбар нигоҳ дошта мешаванд. Email ва рақами телефон талаб намешавад.

1. Маълумоте, ки ҷамъоварӣ мешавад

Ҳангоми регистрация ном, насаб (ихтиёрӣ), синну сол ва логини интихобшуда ба Supabase фиристода шуда, дар профили корбар нигоҳ дошта мешаванд. Паролро танҳо Supabase Auth коркард ва ҳифз мекунад; он дар ҷадвали профил нигоҳ дошта намешавад. Барои сохтани ҳисоби дохилӣ логин ба нишонии техникии хизматрасонӣ пайваст мешавад, аммо корбар email ё рақами телефон ворид намекунад ва паём намегирад.

Ёддошт ва нақшаҳо метавонанд матни шахсӣ дошта бошанд. Сабтҳои молиявӣ маблағ, навъи амалиёт (даромад ё хароҷот), категория, сана ва шарҳи ихтиёриро дар бар мегиранд. Ин маълумот ба Supabase фиристода мешавад. Дар телефон забони интерфейс, XP, шумораи миссияҳои иҷрошуда ва рӯйхати миссияҳои имрӯз нигоҳ дошта мешаванд.

2. Пайвасти шабакавӣ ва амният

Ҳамаи синну солҳо барои истифодаи барнома ҳисоб месозанд. Дархостҳои регистрация ва вход ба Edge Function-и Supabase фиристода мешаванд. Барои маҳдуд кардани кӯшишҳои зиёдатӣ hash-и IP дар механизми маҳдудкунии суръат истифода мешавад; он барои сохтани профил ё рейтинг истифода намешавад.

Маълумоти профил ва сабтҳои шахсӣ ба ҳисоби воридшуда вобастаанд. Сиёсати RLS-и пойгоҳи додаҳо дастрасиро танҳо ба соҳиби сабт иҷозат медиҳад; корбарони дигар ёддоштҳо ва маблағҳои шахсии якдигарро хонда наметавонанд. XP ва пешрафти бозӣ дар телефон мемонанд. Феҳристи оммавии миссияҳо метавонад аз Supabase хонда шавад.

Провайдери Supabase метавонад маълумоти техникии дархост, аз ҷумла суроғаи IP, вақти дархост ва сарлавҳаҳои стандартии HTTP-ро дар журналҳои хизматрасонӣ ва амниятӣ коркард кунад.

3. Иҷозатҳо ва хусусиятҳои истифода нашаванда

  • Ҷойгиршавии дақиқ ё GPS ҷамъоварӣ намешавад.
  • Дастрасӣ ба камера, микрофон, алоқаҳо, SMS ё файлҳо дархост намешавад.
  • Акс ё видео ба сервер бор карда намешавад.
  • Чат, паёмҳои шахсӣ, реклама, таблиғоти мақсаднок ё SDK-и таҳлили рафтор вуҷуд надоранд.
  • Рейтинг ва натиҷаҳои оммавии корбарон дар V1 фаъол нестанд.

4. Нест кардани маълумот

Фармони Танзимот → Нест кардани ҳамаи маълумоти маҳаллӣ сессия ва маълумоти маҳаллиро аз телефон пок мекунад, аммо сабтҳои ёддошт ва молияи дар Supabase нигоҳдошташударо нест намекунад. Ҳар ёддошт ё амалиёти молиявиро аз дохили бахши дахлдор алоҳида нест кардан мумкин аст. Нест кардани ҳисоби серверӣ ҳанӯз аз дохили барнома дастрас нест. Нест кардани барнома низ сабтҳои сервериро нест намекунад.

5. Кӯдакон ва амният

Миссияҳо бояд дар муҳити бехатар иҷро шаванд. Барои корҳои берунӣ, истифодаи асбобҳо ё ҳар фаъолияте, ки иҷозат мехоҳад, кӯдак бояд аз падару модар ё калонсол иҷозат гирад. Холҳо танҳо нишондиҳандаи пешрафти шахсӣ мебошанд; онҳо мукофоти пулӣ, натиҷаи расман тасдиқшуда ё баҳои саломатӣ нестанд.

6. Хизматрасонии беруна

Барнома барои аутентификатсия, нигоҳдории профил ва сабтҳои шахсӣ аз Supabase истифода мебарад. Ҳисоби дохилӣ бо логин ва парол сохта мешавад; email ва телефон аз корбар талаб намешаванд.

7. Тағйирот ба сиёсат

Агар дар версияҳои оянда ҷамъоварӣ ё истифодаи маълумот тағйир ёбад, сиёсати махфият пеш аз нашри он версия нав карда мешавад. Хусусиятҳои оянда то эълони расмӣ фаъол ҳисоб намешаванд.

8. Тамос

Барои саволҳо ё гузориши мушкилоти махфият аз саҳифаи Issues дар GitHub истифода баред. Маълумоти шахсии ҳассосро дар масъалаҳои оммавӣ нанависед.

Privacy Policy — English

Last updated: 25 November 2026 · Version 1.0.0

Summary: registration is required for every user. The profile, personal notes, plans, reports, events, and income/expense records are stored in Supabase under the signed-in account. Users do not provide a real email address or phone number.

1. Data collected

During registration, first name, optional last name, age, and chosen username are sent to Supabase and stored in the user's profile. Supabase Auth handles and protects the password; it is not stored in the profile table. The service creates an internal technical email identity from the username, but users do not enter a real email address or phone number and do not receive email.

Notes and plans may contain personal text. Financial records include the amount, income/expense type, category, date, and optional comment. These records are sent to Supabase. Interface language, XP, completed mission count, and today's completed mission IDs remain in app-private local storage.

2. Network access and security

All users must create an account. Registration and sign-in requests are sent to a Supabase Edge Function. A hashed IP value is used for rate limiting to reduce abusive attempts; it is not used to create a profile or leaderboard.

Profile and personal records are associated with the signed-in account. Database Row Level Security (RLS) restricts each record to its owner, so other users cannot read another account's notes or financial entries. Game progress and XP remain on the device. The public mission catalogue may be read from Supabase.

Supabase may process technical request information, including IP address, request time, and standard HTTP headers, in operational and security logs.

3. Permissions and features not used

  • No precise location or GPS collection.
  • No camera, microphone, contacts, SMS, or file access is requested.
  • No photo or video is uploaded to a server.
  • No chat, direct messages, advertising, targeted ads, or behavioural analytics SDKs.
  • No public leaderboard or user-to-user ranking in V1.

4. Deleting data

Settings → Delete all local data clears local data and sign-in state on the device, but it does not delete notes or financial entries stored in Supabase. Individual notes and financial entries can be deleted from their respective app sections. Deleting the server account is not yet available inside the app. Uninstalling the app does not delete server records.

5. Children and safety

Activities should be completed safely. A child must ask a parent or responsible adult before outdoor activities, using tools, or doing anything that requires permission. Points represent personal progress only; they are not money, official verification, or a health assessment.

6. Third-party service

The app uses Supabase for authentication, profile storage, and personal records. Accounts use a username and password; users are not asked for a real email address or phone number.

7. Policy changes

Any future change to data collection or use will be reflected here before the affected app version is released. Planned features are not active features.

8. Contact

For privacy questions or to report an issue, use the GitHub issue tracker. Do not post sensitive personal information in public issues.

Политика конфиденциальности — Русский

Обновлено: 25 ноября 2026 · Версия 1.0.0

Кратко: регистрация обязательна для всех пользователей. Профиль, личные заметки, планы, отчёты, события и записи о доходах/расходах хранятся в Supabase в рамках аккаунта пользователя. Настоящий email и номер телефона не требуются.

1. Собираемые данные

При регистрации имя, необязательная фамилия, возраст и выбранный логин отправляются в Supabase и сохраняются в профиле пользователя. Пароль обрабатывается и защищается Supabase Auth; в таблице профилей он не хранится. Сервис создаёт внутреннюю техническую email-идентичность на основе логина, но пользователь не вводит настоящий email или номер телефона и не получает письма.

Заметки и планы могут содержать личный текст. Финансовые записи включают сумму, тип операции, категорию, дату и необязательный комментарий; эти данные отправляются в Supabase. Язык интерфейса, XP, число выполненных заданий и список заданий за сегодня хранятся локально.

2. Сеть и безопасность

Регистрация обязательна для всех пользователей. Запросы регистрации и входа отправляются в Supabase Edge Function. Хеш IP используется для ограничения частоты попыток и защиты от злоупотреблений; он не используется для создания профиля или рейтинга.

Профиль и личные записи привязаны к вошедшему аккаунту. Политики Row Level Security (RLS) ограничивают доступ владельцем записи; другие пользователи не могут читать чужие заметки и финансовые операции. Игровой прогресс и XP остаются на устройстве. Публичный список заданий может считываться из Supabase.

Supabase может обрабатывать технические данные запросов, включая IP-адрес, время запроса и стандартные HTTP-заголовки, в служебных и защитных журналах.

3. Разрешения и функции, которые не используются

  • Точное местоположение и GPS не собираются.
  • Камера, микрофон, контакты, SMS и доступ к файлам не запрашиваются.
  • Фотографии и видео на сервер не загружаются.
  • Нет чата, личных сообщений, рекламы, таргетированной рекламы и SDK поведенческой аналитики.
  • В V1 нет публичного рейтинга или сравнения пользователей.

4. Удаление данных

Команда Настройки → Удалить все локальные данные очищает локальные данные и состояние входа на устройстве, но не удаляет заметки и финансовые записи, сохранённые в Supabase. Каждую заметку и финансовую запись можно удалить отдельно в соответствующем разделе приложения. Удаление серверного аккаунта пока недоступно внутри приложения. Удаление приложения также не удаляет серверные записи.

5. Дети и безопасность

Задания необходимо выполнять безопасно. Перед занятиями на улице, использованием инструментов или другими действиями, требующими разрешения, ребёнок должен спросить родителя или ответственного взрослого. Очки показывают только личный прогресс; это не деньги, не официальное подтверждение и не медицинская оценка.

6. Внешний сервис

Приложение использует Supabase для аутентификации, хранения профиля и личных записей. Для аккаунта используются логин и пароль; настоящий email и номер телефона не требуются.

7. Изменения политики

Любые будущие изменения сбора или использования данных будут отражены здесь до выпуска соответствующей версии. Запланированные функции не являются активными функциями.

8. Контакты

По вопросам конфиденциальности используйте GitHub Issues. Не публикуйте чувствительные персональные данные в открытых обращениях.
