Сиёсати махфият

Охирин навсозӣ: 24 ноябри 2026

Хулоса: сабти ном дар сомона аз 7-солагӣ ҳатмист. Ном, насаб, синну сол, логин ва ID-и ягона дар Supabase нигоҳ дошта мешаванд. Паролро Supabase Auth коркард мекунад; он дар ҷадвали профил сабт намешавад. Почта ва телефон талаб карда намешаванд.

1. Маълумоте, ки ҳангоми сабти номи сомона ҷамъ мешавад

  • Ном ва насаб.
  • Синну сол (аз 7 то 120).
  • Логини интихобкардаи корбар.
  • ID-и ягонаи UUID, ки ҳангоми сохтани ҳисоб ба таври автоматӣ дода мешавад, ва вақти сохтани ҳисоб.
  • Маълумоти аутентификатсия, ки Supabase Auth барои санҷиши парол ва идоракунии сессия истифода мебарад.

Парол дар ҷадвали профили SHAHRVAND нигоҳ дошта намешавад ва ҳамчун матни одӣ ба корбарон ё дигар шаҳрвандон намоиш дода намешавад. Барои воридшавӣ почтаи электронӣ ё рақами телефон лозим нест; логин ҳамчун номи воридшавӣ истифода мешавад.

2. Барои чӣ маълумот истифода мешавад

Маълумот барои сохтани ҳисоби шахсӣ, воридшавии такрорӣ, шинохтани профили худи корбар ва додани ID-и ягона истифода мешавад. Ҳар корбар тавассути сиёсати амнияти пойгоҳи додаҳо танҳо профили худро хонда метавонад. Дар айни ҳол рӯйхати оммавии профилҳо ё рейтинги воқеии корбарон дар сомона фаъол нест.

3. Маълумоти кӯдакон

Сабти ном аз 7-солагӣ имкон дорад. Барои корбарони то 18-сола падару модар ё васӣ бояд аз сабти ном огоҳ бошанд ва иҷозат диҳанд. Формаи сомона шахсияти падару модар ё васиро мустақилона тасдиқ намекунад; ин санҷиш ҳоло дар система фаъол нест.

4. Парол, логин ва барқарорсозии ҳисоб

Парол тавассути Supabase Auth санҷида ва нигоҳдорӣ мешавад; барнома онро дар ҷадвали профил ҳамчун матни одӣ сабт намекунад. Логин бояд аз 4 то 24 аломати лотинӣ, рақам, нуқта, хатти поён ё дефис иборат бошад ва такрорӣ буда наметавонад.

Ҳангоми сабти ном почта ё телефон ҷамъ намешавад. Аз ин сабаб барқарорсозии худкори пароли фаромӯшшуда тавассути почта ё SMS ҳоло дастрас нест. Логин ва паролро дар ҷойи бехатар нигоҳ доред. Дархости кӯмакро тавассути GitHub Issues фиристодан мумкин аст; маълумоти махфиро дар масъалаи оммавӣ нанависед.

5. Нигоҳдорӣ, амният ва хизматрасониҳои беруна

Маълумоти профил дар пойгоҳи додаи Supabase нигоҳ дошта мешавад. Дастрасӣ бо Row Level Security маҳдуд шудааст: корбари воридшуда танҳо профили ба ID-и ҳисоби худ тааллуқдоштаро хонда метавонад. Пароли махфӣ ба браузер ё ҷадвали профил баргардонида намешавад.

Барои пешгирӣ аз кӯшишҳои аз ҳад зиёди сабти ном ва воридшавӣ, система шакли ҳешшудаи нишондиҳандаи шабакавии дархостро дар равзанаҳои маҳдуди вақт истифода мебарад. Сабтҳои кӯҳна ҳангоми дархостҳои минбаъдаи аутентификатсия тоза карда мешаванд. Худи суроғаи IP дар ҷадвали ин маҳдудиятҳо нигоҳ дошта намешавад.

Провайдери хизматрасонӣ метавонад маълумоти техникии зарурии дархостҳоро тибқи сиёсати худ коркард кунад. Маълумоти бештар: Supabase Privacy.

6. Барномаи Android ва маълумоти маҳаллӣ

Барномаи Android-и версияи 1.0.0 ҳоло аз ҳисоби сомона ҷудо аст. Тахаллус, гурӯҳи синнусолӣ, забон, XP ва пешрафти дохили бозӣ дар хотираи хусусии телефон нигоҳ дошта мешаванд ва бо ҳисоби сомона ҳамоҳанг намешаванд. Ин маънои онро надорад, ки профили сомона низ танҳо дар телефон нигоҳ дошта мешавад.

Дар версияи Android функсияҳои GPS, камера, микрофон, чат, реклама ва боркунии акс ё видео ба сервер истифода намешаванд.

7. Ҳуқуқи корбар ва дархостҳо

Дар версияи ҷорӣ тугмаи худхизматрасонии нест кардани ҳисоби серверӣ ё барқарорсозии парол мавҷуд нест. Барои дархости ислоҳ ё нест кардани профил аз GitHub Issues истифода баред ва логин, парол ё маълумоти ҳассосро дар масъалаи оммавӣ нанависед.

8. Тамос ва тағйирот

Агар тарзи коркарди маълумот дар версияҳои оянда тағйир ёбад, ин саҳифа нав карда мешавад. Хусусиятҳое, ки ҳоло нашр нашудаанд, фаъол ҳисоб намешаванд.

Privacy Policy — English

Last updated: 24 November 2026

Summary: website registration is required from age 7. The site stores a first name, surname, age, chosen username, and unique account ID in Supabase. Supabase Auth handles the password; it is not stored in the profile table. No email address or phone number is required.

1. Website account data

  • First name and surname.
  • Age (7–120).
  • The username selected by the user.
  • A unique UUID assigned automatically and the account creation time.
  • Authentication data processed by Supabase Auth to verify passwords and manage sessions.

The password is not stored in the SHAHRVAND profile table or shown to other users. A user signs in with a username; an email address or phone number is not requested.

2. How the data is used

Data is used to create an account, allow repeat sign-ins, identify the account owner's profile, and assign a unique ID. Database security policies restrict each signed-in user to reading their own profile. A public user directory or real user leaderboard is not active on the website at this time.

3. Children

Website registration is available from age 7. For users under 18, a parent or guardian should know about and approve the registration. The website form does not independently verify a parent's or guardian's identity; that verification is not currently implemented.

4. Passwords, usernames, and account recovery

Supabase Auth handles password verification and storage; the app does not save a plain-text password in the profile table. A username must contain 4–24 Latin letters, digits, dots, underscores, or hyphens and must be unique.

No email or phone number is collected during registration. Therefore, automatic password recovery by email or SMS is not currently available. Keep the username and password in a safe place. You may request help through GitHub Issues; do not post passwords or sensitive data in a public issue.

5. Storage, security, and service providers

Profile data is stored in Supabase. Row Level Security restricts a signed-in user to reading the profile associated with their own account ID. The password is not returned to the browser or stored in the profile table.

To prevent excessive registration and login attempts, the system uses a hashed form of a network request identifier in limited time windows. Old rate-limit records are cleaned during later authentication requests. The raw IP address is not stored in that rate-limit table.

The service provider may process necessary technical request information under its own privacy policy. See Supabase Privacy.

6. Android app and local data

Android app version 1.0.0 is currently separate from the website account. Its nickname, age band, language, XP, and game progress are stored in private app storage on the device and are not synchronised with the website account. This does not mean that the website account is stored only on the device.

The Android version does not use GPS, camera, microphone, chat, advertising, or server photo/video uploads.

7. User requests

The current version does not provide self-service server-account deletion or password recovery. To request a profile correction or deletion, use GitHub Issues. Do not post usernames together with passwords or other sensitive details in public issues.

8. Contact and changes

This page will be updated if data practices change in a future release. Features that have not been released are not active.

Политика конфиденциальности — Русский

Обновлено: 24 ноября 2026 года

Кратко: регистрация на сайте обязательна с 7 лет. В Supabase сохраняются имя, фамилия, возраст, выбранный логин и уникальный ID аккаунта. Пароль обрабатывает Supabase Auth; он не хранится в таблице профилей. Электронная почта и номер телефона не требуются.

1. Данные веб-аккаунта

  • Имя и фамилия.
  • Возраст (от 7 до 120 лет).
  • Выбранный пользователем логин.
  • Автоматически созданный уникальный UUID и время создания аккаунта.
  • Данные аутентификации, которые Supabase Auth использует для проверки пароля и управления сессиями.

Пароль не хранится в таблице профилей SHAHRVAND и не показывается другим пользователям. Для входа используется логин; адрес электронной почты и номер телефона не запрашиваются.

2. Использование данных

Данные нужны для создания аккаунта, повторного входа, идентификации собственного профиля и назначения уникального ID. Политики безопасности базы данных позволяют вошедшему пользователю читать только собственный профиль. Публичный каталог пользователей и реальный рейтинг на сайте пока не активны.

3. Дети

Регистрация на сайте доступна с 7 лет. Для пользователей младше 18 лет родитель или опекун должен знать о регистрации и разрешить её. Форма сайта самостоятельно не проверяет личность родителя или опекуна; такая проверка пока не реализована.

4. Пароль, логин и восстановление доступа

Проверку и хранение пароля выполняет Supabase Auth; приложение не сохраняет пароль открытым текстом в таблице профилей. Логин должен содержать 4–24 латинских буквы, цифры, точки, подчёркивания или дефисы и быть уникальным.

При регистрации электронная почта и номер телефона не собираются. Поэтому автоматическое восстановление пароля через почту или SMS пока недоступно. Храните логин и пароль в безопасном месте. Запросить помощь можно через GitHub Issues; не публикуйте пароль и другие чувствительные данные в открытом обращении.

5. Хранение, безопасность и сторонние сервисы

Данные профиля хранятся в Supabase. Row Level Security ограничивает вошедшего пользователя чтением профиля, связанного с его собственным ID. Пароль не возвращается браузеру и не сохраняется в таблице профилей.

Для защиты от чрезмерного количества регистраций и попыток входа система использует хешированную форму сетевого идентификатора в ограниченных временных окнах. Старые записи лимитов очищаются во время последующих запросов аутентификации. Исходный IP-адрес в этой таблице лимитов не хранится.

Поставщик сервиса может обрабатывать необходимые технические данные запросов в соответствии со своей политикой. Подробнее: Supabase Privacy.

6. Android-приложение и локальные данные

Android-приложение версии 1.0.0 пока не связано с веб-аккаунтом. Псевдоним, возрастная группа, язык, XP и игровой прогресс хранятся в приватном хранилище приложения на устройстве и не синхронизируются с веб-аккаунтом. Это не означает, что веб-аккаунт хранится только на устройстве.

В Android-версии не используются GPS, камера, микрофон, чат, реклама и загрузка фото или видео на сервер.

7. Запросы пользователя

В текущей версии нет самостоятельного удаления серверного аккаунта или восстановления пароля. Для исправления или удаления профиля используйте GitHub Issues. Не публикуйте логин вместе с паролем или другими чувствительными данными в открытых обращениях.

8. Контакты и изменения

При изменении обработки данных в будущих версиях эта страница будет обновлена. Не выпущенные функции не считаются активными.
