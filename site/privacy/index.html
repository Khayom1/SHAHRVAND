Сиёсати махфият

Охирин навсозӣ: 24 ноябри 2026

Хулоса: барои синни то 18 сола барнома маълумоти профил ё пешрафтро ба сервер намефиристад. Барнома GPS, микрофон, камера, чат, реклама ё таҳлилгари рафтор надорад.

1. Маълумоте, ки дар телефон нигоҳ дошта мешавад

Барнома метавонад тахаллуси ихтиёрӣ, гурӯҳи синнусолӣ, забони интерфейс, холҳои XP, шумораи миссияҳои иҷрошуда ва рӯйхати миссияҳои имрӯзаро дар хотираи маҳаллии барнома нигоҳ дорад. Номи ҳақиқӣ, насаб, санаи таваллуд, рақами телефон ва почтаи электронӣ талаб карда намешаванд.

2. Гурӯҳҳои синнусолӣ ва пайвасти шабакавӣ

7–12 ва 13–17 сола

Барнома феҳристи миссияҳои дохилиро истифода мебарад. Дар ин режим дархости шабакавӣ ба Supabase ё дигар сервер иҷро намешавад. Профил, тахаллус, синну сол ва пешрафт дар дастгоҳ мемонанд.

18+ сола

Барнома метавонад танҳо феҳристи оммавии миссияҳоро аз Supabase бо дархости хонданӣ (HTTP GET) нав кунад. Тахаллус, гурӯҳи синнусолӣ, XP, таърихи миссияҳо ё маълумоти профил ба ин дархост дохил карда намешаванд. Агар сервер дастрас набошад, барнома феҳристи дохилиро истифода мебарад.

Ҳангоми дархости шабакавии 18+ провайдер метавонад маълумоти техникии зарурӣ, аз ҷумла суроғаи IP, вақти дархост ва сарлавҳаҳои стандартии HTTP-ро дар журналҳои амниятӣ ва хизматрасонӣ коркард кунад. Ин маълумот аз ҷониби барнома барои сохтани профил ё рейтинг истифода намешавад.

3. Иҷозатҳо ва хусусиятҳои истифода нашаванда

  • Ҷойгиршавии дақиқ ё GPS ҷамъоварӣ намешавад.
  • Дастрасӣ ба камера, микрофон, алоқаҳо, SMS ё файлҳо дархост намешавад.
  • Акс ё видео ба сервер бор карда намешавад.
  • Чат, паёмҳои шахсӣ, реклама, таблиғоти мақсаднок ё SDK-и таҳлили рафтор вуҷуд надоранд.
  • Рейтинг ва натиҷаҳои оммавии корбарон дар V1 фаъол нестанд.

4. Чӣ гуна маълумотро нест кардан мумкин аст

Дар дохили барнома ба Танзимот → Нест кардани ҳамаи маълумоти маҳаллӣ гузаред. Ин профил, XP ва пешрафти дар телефон нигоҳдоштаро нест мекунад. Нест кардани барнома низ маълумоти хусусии маҳаллии онро аз дастгоҳ пок мекунад. Дар V1 профили серверӣ вуҷуд надорад.

5. Кӯдакон ва амният

Миссияҳо бояд дар муҳити бехатар иҷро шаванд. Барои корҳои берунӣ, истифодаи асбобҳо ё ҳар фаъолияте, ки иҷозат мехоҳад, кӯдак бояд аз падару модар ё калонсол иҷозат гирад. Холҳо танҳо нишондиҳандаи пешрафти шахсӣ мебошанд; онҳо мукофоти пулӣ, натиҷаи расман тасдиқшуда ё баҳои саломатӣ нестанд.

6. Хизматрасониҳои беруна

Барои нав кардани феҳристи оммавии миссияҳо дар гурӯҳи 18+ барнома аз API-и Supabase истифода мебарад. Барои гурӯҳҳои то 18 сола чунин дархостҳо иҷро намешаванд. Барнома ҳисоб ё аутентификатсияи Supabase эҷод намекунад.

7. Тағйирот ба сиёсат

Агар дар версияҳои оянда ҷамъоварӣ ё истифодаи маълумот тағйир ёбад, сиёсати махфият пеш аз нашри он версия нав карда мешавад. Хусусиятҳои оянда то эълони расмӣ фаъол ҳисоб намешаванд.

8. Тамос

Барои саволҳо ё гузориши мушкилоти махфият аз саҳифаи Issues дар GitHub истифода баред. Маълумоти шахсии ҳассосро дар масъалаҳои оммавӣ нанависед.

Privacy Policy — English

Last updated: 24 November 2026 · Version 1.0.0

Summary: users under 18 do not send profile or progress data to a server. The app does not use GPS, microphone, camera, chat, advertising, or behavioural analytics.

1. Data stored on the device

The app may store an optional nickname, selected age band, interface language, XP, completed mission count, and today's completed mission IDs in app-private local storage. A real name, surname, date of birth, phone number, or email address is not required.

2. Age groups and network access

Ages 7–12 and 13–17

The app uses its bundled mission catalogue and makes no network requests to Supabase or another application server. Profile details, nickname, age band, and progress remain on the device.

Ages 18+

The app may make a read-only HTTP GET request to Supabase to refresh the public mission catalogue. The request does not include the nickname, age band, XP, mission history, or profile data. If the service is unavailable, the app uses its bundled catalogue.

For an 18+ catalogue request, the service provider may process basic technical request information such as IP address, request time, and standard HTTP headers in operational or security logs. The app does not use this information to create a profile or leaderboard.

3. Permissions and features not used

  • No precise location or GPS collection.
  • No camera, microphone, contacts, SMS, or file access is requested.
  • No photo or video is uploaded to a server.
  • No chat, direct messages, advertising, targeted ads, or behavioural analytics SDKs.
  • No public leaderboard or user-to-user ranking in V1.

4. Deleting local data

Open Settings → Delete all local data to remove the local profile, XP, and progress. Uninstalling the app also removes its app-private local data. V1 does not create a server-side user profile.

5. Children and safety

Activities should be completed safely. A child must ask a parent or responsible adult before outdoor activities, using tools, or doing anything that requires permission. Points represent personal progress only; they are not money, official verification, or a health assessment.

6. Third-party service

For the public mission catalogue only, the 18+ mode may use the Supabase API. Users under 18 do not make these requests. The app does not create a Supabase account or authenticate a user.

7. Policy changes

Any future change to data collection or use will be reflected here before the affected app version is released. Planned features are not active features.

8. Contact

For privacy questions or to report an issue, use the GitHub issue tracker. Do not post sensitive personal information in public issues.

Политика конфиденциальности — Русский

Обновлено: 24 ноября 2026 · Версия 1.0.0

Кратко: пользователи младше 18 лет не отправляют профиль или прогресс на сервер. В приложении нет GPS, микрофона, камеры, чата, рекламы и поведенческой аналитики.

1. Данные на устройстве

Приложение может хранить на устройстве необязательный игровой псевдоним, выбранную возрастную группу, язык интерфейса, XP, количество выполненных заданий и список заданий за сегодня. Настоящее имя, фамилия, дата рождения, телефон и электронная почта не требуются.

2. Возрастные группы и сеть

7–12 и 13–17 лет

Приложение использует встроенный список заданий и не отправляет сетевые запросы в Supabase или другой сервер приложения. Профиль, псевдоним, возрастная группа и прогресс остаются на устройстве.

18+ лет

Приложение может выполнить только GET-запрос к Supabase для обновления публичного списка заданий. Псевдоним, возрастная группа, XP, история заданий и данные профиля в запрос не включаются. При недоступности сервера используется встроенный список.

При запросе для режима 18+ поставщик сервиса может обрабатывать технические данные запроса, например IP-адрес, время запроса и стандартные HTTP-заголовки, в служебных журналах и целях безопасности. Приложение не использует их для создания профиля или рейтинга.

3. Разрешения и функции, которые не используются

  • Точное местоположение и GPS не собираются.
  • Камера, микрофон, контакты, SMS и доступ к файлам не запрашиваются.
  • Фотографии и видео на сервер не загружаются.
  • Нет чата, личных сообщений, рекламы, таргетированной рекламы и SDK поведенческой аналитики.
  • В V1 нет публичного рейтинга или сравнения пользователей.

4. Удаление локальных данных

Откройте Настройки → Удалить все локальные данные, чтобы удалить локальный профиль, XP и прогресс. Удаление приложения также удаляет его локальные данные. В V1 серверный профиль пользователя не создаётся.

5. Дети и безопасность

Задания необходимо выполнять безопасно. Перед занятиями на улице, использованием инструментов или другими действиями, требующими разрешения, ребёнок должен спросить родителя или ответственного взрослого. Очки показывают только личный прогресс; это не деньги, не официальное подтверждение и не медицинская оценка.

6. Внешний сервис

Только для обновления публичного списка заданий режим 18+ может использовать API Supabase. Пользователи младше 18 лет такие запросы не выполняют. Приложение не создаёт аккаунт Supabase и не выполняет аутентификацию пользователя.

7. Изменения политики

Любые будущие изменения сбора или использования данных будут отражены здесь до выпуска соответствующей версии. Запланированные функции не являются активными функциями.

8. Контакты

По вопросам конфиденциальности используйте GitHub Issues. Не публикуйте чувствительные персональные данные в открытых обращениях.
